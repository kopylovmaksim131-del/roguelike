# Дизайн-документ: XYZRoguelike

## 1. Общее описание игры

**Жанр:** 2D top-down roguelike с процедурной генерацией уровней.

**Цель игры:** Прокладывать путь через лабиринты, побеждать врагов и боссов, продвигаясь от уровня к уровню. Игрок побеждает, когда зачищает последний уровень.

**Главный герой:** Безымянный игрок, управляемый с клавиатуры. Имеет здоровье, броню, урон, скорость, инвентарь.

**Враги:** Два типа обычных врагов (ближний и дальний бой) и два босса (маг со снарядами и суммонер, призывающий миньонов).

**Что нужно делать:**
- Исследовать лабиринт
- Убивать врагов
- Собирать лут (зелья)
- Спускаться на следующий уровень через дверь
- Побеждать боссов
- Выживать

## 2. Список механик и фич

### Движение и управление
- WASD — перемещение
- Space — атака
- 1-4 — использование зелий

### Уровни
- Процедурная генерация лабиринта (DFS)
- Чередование обычных и босс-уровней
- Переходы с затемнением экрана
- Случайный выбор босса

### Враги
- Ближний бой
- Дальний бой (снаряды)
- Преследование игрока

### Боссы
- **Mage:** AOE-атака, самонаводящиеся снаряды, веерный залп, усиление во второй фазе
- **Summoner:** призыв миньонов (ближников и дальников), усиление во второй фазе
- Фазы босса (изменение поведения при 50% HP)

### Инвентарь
- Подбор предметов через триггеры
- Четыре типа зелий: лечение, броня, скорость, сила
- Использование по клавишам 1-4
- Эффекты: восстановление HP/брони, увеличение скорости/урона

### Движок
- Компонентная архитектура
- Физика и коллизии
- Камера, следящая за игроком
- Анимация персонажа
- Логирование
- Сохранение характеристик игрока между уровнями

### Что добавлено в рамках дипломного проекта
- Инвентарь с предметами
- Боссы с уникальными способностями
- Смена фаз боссов
- Система переходов с затемнением

## 5. Работа с Git

### Ветки

- `main` - стабильная версия, готовая к сдаче
- `features/issue-5` - основная рабочая ветка разработки
- `features/level-changes` - переходы между уровнями, смена локаций
- `features/bosses` - боссы и их способности
- `features/inventory` - инвентарь, лут, зелья

### Процесс

1. Для каждой крупной фичи создавалась отдельная ветка (`features/bosses`, `features/inventory`, `features/level-changes`)
2. Разработка велась в соответствующей ветке
3. После завершения фичи ветка сливалась в `main`
4. Pull Request для каждого слияния

### Ключевые коммиты

- `add player and enemy` — добавление игрока и врагов
- `refactor: rework player creation and add enemy factory` — переработка создания игрока, фабрика врагов
- Коммиты с боссами, инвентарём, лутом, переходами между уровнями

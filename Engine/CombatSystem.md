
# Боевая система

## Общее описание

Боевая система построена на компоненте MeleeAttackComponent. Он добавляется к любому игровому объекту и позволяет атаковать другие объекты в ближнем бою.
Компонент работает в двух режимах. В автоматическом (autoAttack = true) объект сам атакует все цели из списка, когда проходит кулдаун - это используется врагами. В ручном (autoAttack = false) объект ждёт внешнего сигнала shouldAttack - это используется игроком при нажатии пробела.
При атаке для каждой цели проверяется расстояние. Если цель в радиусе attackRadius, наносится урон. Урон сначала проходит через броню (ArmorComponent), остаток идёт в здоровье (HealthComponent).
Мёртвые цели автоматически удаляются из списка после атаки. При установке новых целей через SetTargets компонент подписывается на их смерть - если цель умирает в любой момент, она удаляется из списка.
Игрок ищет цели по направлению последнего движения: собирает всех, кто находится в секторе примерно 90 градусов перед ним и в радиусе атаки. Враг атакует конкретную цель, переданную ему при создании.

## Параметры
- Задержка между атаками задаётся через SetAttackCooldownTime в секундах.

- Радиус атаки задаётся через SetAttackRadius в пикселях.

- Урон за атаку задаётся через SetDamage в целых числах.

- Режим атаки задаётся через SetAttackMode. Значение true включает автоатаку для врагов, false — ручной режим для игрока.

- Флаг атаки shouldAttack взводится извне для игрока по нажатию пробела. Компонент проверяет его каждый кадр и, если флаг взведён и кулдаун прошёл, выполняет атаку.

- Список целей устанавливается через SetTargets. Для врага это обычно один объект - игрок. Для игрока список собирается методом FindTargets по направлению движения.

## Пример

auto attack = gameObject->AddComponent<XYZEngine::MeleeAttackComponent>();
attack->SetAttackRadius(220.f);
attack->SetAttackCooldownTime(1.f);
attack->SetDamage(15);

# XYZRoguelike

Учебный 2D-рогалик на собственном движке. Игрок перемещается по лабиринту, сражается с врагами, побеждает боссов и переходит на следующие уровни.

## Особенности

- Собственный движок на компонентах (физика, коллизии, камера, анимация)
- Генерация лабиринта алгоритмом DFS
- Обычные враги и два типа боссов с уникальными способностями
- Инвентарь с зельями (лечение, броня, сила, скорость)
- Переходы между уровнями с затуханием экрана
- Сохранение характеристик игрока между уровнями

## Управление

- WASD — движение
- Пробел — атака
- 1-4 — использование зелий

## Сборка и запуск

1. Открыть `Game.sln` в Visual Studio 2022
2. Собрать решение (Ctrl+Shift+B)
3. Запустить (F5)

Требования: Visual Studio 2022, SFML 2.5.1 (включён в проект).

## Структура

- `Engine/` — движок (DLL): компоненты, физика, рендер, ресурсы
- `ArkanoidGame/` — игра (EXE): уровни, боссы, инвентарь, лут
